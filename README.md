# HaramBall FC

An educational Qt Widgets app about the 2026 FIFA World Cup. Learn the rules, history, and key moments of the tournament through lessons, quizzes, and games all in a pixel art theme.

## Features

### Fan Mode
- 4 lessons covering World Cup qualifications, countries represented, rules & regulations, and tournament history
- 10-question combined quiz to review all lessons
- Juggling mini-game

### Player Mode
- Same 4 lessons with per-lesson quizzes
- Penalty kick game

### Bracket
- Official 2026 FIFA World Cup group stage (Groups A–L, all 48 teams)
- Full knockout bracket (Round of 32 through the Final)
